项目周报（示例文档）
====================

本周工作总结：
1. 完成了 RAG 私有知识库问答系统的核心检索链路开发，实现了向量检索与 BM25 关键词检索的混合召回，并通过 Rerank 交叉编码器对候选片段进行精排，显著降低了回答中的幻觉比例。
2. 搭建了基于 FastAPI 的流式问答接口（SSE），前端使用 Streamlit 实现聊天界面，支持引用溯源展示。
3. 使用 Docker Compose 完成 MySQL、Qdrant、API 服务与前端四容器的一键部署，并在本机完成端到端验证。

遇到的问题：
- 海外搜索 API 在部分网络环境下不可达，已改为使用国内可达的搜索引擎后端。
- PDF 扫描件无法直接解析文本，需要后续接入 OCR 能力。

下周计划：
- 完善检索评估脚本，量化召回率与命中率。
- 增加文档增量更新能力，避免每次全量重建索引。
